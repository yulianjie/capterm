# CapTerm 应用图标备选

六个方向都以 SSH 工作台和 Captain 的航海意象为起点。SVG 采用统一的 256 单位画布与圆角底板，可以放在一起比较轮廓、符号和小尺寸辨识度。

| 方案 | 图形寓意 |
| --- | --- |
| [01 · 破浪船艏](01-ship.svg)（已选用） | 以大船侧影呼应 Captain，船身镂空形成终端提示符 `>_`。 |
| [02 · 指令舵轮](02-helm.svg) | 六柄舵轮围住命令提示符，品红光标沿用工作台的航线色。 |
| [03 · 灯塔信标](03-beacon.svg) | 灯塔的双向光束呼应远程连接，塔身保留终端提示符。 |
| [04 · 指令罗盘](04-compass.svg) | 两个错开的代码尖括号组成罗盘针。 |
| [05 · 锚形密钥](05-anchor.svg) | 锚环兼作钥匙环，品红齿口点出 SSH 密钥。 |
| [06 · 跳板航线](06-route.svg) | 一条品红航线把本机、跳板和远端连在一起。 |
