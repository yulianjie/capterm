每一次连接都是一条航线

CapTerm 是用 Rust 和 gpui-kit 开发的 SSH 远程管理程序：左侧 SFTP 文件，中间是带行号和逐行时间的终端，右侧是会话和主机监控，底部是命令输入栏。品红色的航线只用来表示连接链路——从本机出发，经过跳板机，到达目标主机；界面的其余部分保持安静，把注意力留给终端。

终端可追溯每一行都有行号和写入时间，命令带退出码和耗时，空闲超过一分钟会插入间隔线。
为 TUI 和 Agent CLI 而做备用屏幕、Kitty 键盘协议、括号粘贴、同步输出、OSC 通知；内联 TUI 的重绘区单独标记为「实时」。
深浅两套等价主题每个颜色分别取值并校验对比度，附带可直接加载的 gpui-kit 主题文件。

画板

全部由同一个交互原型渲染导出（1440×900，2 倍图）。点击图片查看原图，点击「打开原型」进入对应场景并继续操作。

航线的几种状态

航线条位于每个终端标签下方。线段上是这一跳的往返延迟；空心圆环是目标主机。同一套图形也用在会话列表（迷你航线表示跳数）和会话编辑器（纵向航线，见画板 07）。

取值直接读取原型使用的 tokens.css。强调色只表示「可交互、已选中」，航线色只表示连接链路，状态色必须同时配图标或文字。

字体

界面使用 Noto Sans SC；终端、编辑器、路径和主机名使用 Maple Mono NF CN——中文字宽严格是英文的两倍，TUI 的边框和表格不会因为中文错位。
